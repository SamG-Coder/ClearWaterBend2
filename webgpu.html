What actually runs where?
Bend owns the spectra, FFTs, choppy surface and optical renderer. Clang reads the upstream-generated CUDA device program. Its functions and control flow are translated directly into compiled WGSL functions. The adapter preserves Bend's 64-bit integer tags as pairs of 32-bit words and supplies WebGPU task queues and memory allocation. Browser JavaScript schedules compute dispatches, copies the final pixels and updates this page. There is no bytecode interpreter or CPU rendering fallback.
The adapter targets this pinned Bend compiler and its pure image program. It does not implement arbitrary CUDA, native IO or the full original Clearwater effects.
